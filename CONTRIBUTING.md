# Contributing

1. Fork the repository and create a branch for your change.
2. Install dependencies with `npm install`.
3. Run `npm run dev` while developing, or `npm run build` to type-check and create a production bundle.
4. Test the plugin in an Obsidian vault connected to a Paperless-ngx instance.
5. Open a pull request that clearly describes the change and any manual testing performed.

Please keep changes focused and avoid committing generated files other than the plugin bundle required for a release.
